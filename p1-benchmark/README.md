Dataset: FLORES+ devtest (CC BY-SA 4.0), English source with Russian and Spanish references.
Locales: rus_Cyrl and spa_Latn. Russian is my native language, so I can defend every score in front of a native reviewer; Spanish is a high-resource language where I expect models to be strong, which gives the benchmark a contrast.
Sampling: 60 segments of 12+ words, spread across topics, random seed 42, with manual swaps where a segment didn't work.
